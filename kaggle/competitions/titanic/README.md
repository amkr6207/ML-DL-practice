# Titanic Solution - Kaggle

## Prerequisites
1.  **Environment**: `hello-env` (conda).
    ```bash
    conda activate hello-env
    ```
2.  **Data**: Place `train.csv`, `test.csv` in the `data/` directory.

## Usage
Run the solution script:
```bash
python solve_titanic.py
```

## Output
- `submission.csv`: Predictions for the test set.
- Console output shows validation accuracy.

## Results
- **CV Accuracy**: ~0.834
